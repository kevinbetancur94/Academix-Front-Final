# Guía de uso de Academix

## 1. Objetivo
Esta guía describe los pasos básicos para instalar, iniciar y navegar por el proyecto Academix.

## 2. Preparación
Antes de comenzar, verifica que tengas Node.js y npm instalados.

## 3. Instalar dependencias
Desde la carpeta raíz del proyecto, ejecuta:

```bash
npm install
```

## 4. Iniciar la aplicación
Ejecuta el siguiente comando:

```bash
npm run dev
```

Abre en el navegador la dirección local que muestre la terminal.

## 5. Navegación
Utiliza las opciones de navegación disponibles en la aplicación para acceder a las secciones implementadas.

La disponibilidad de cada sección depende de que sus componentes y datos estén integrados correctamente.

## 6. Verificación
Para comprobar el código, ejecuta:

```bash
npm run lint
npm run build
```

Si aparece un error, revisa el mensaje de la terminal y consulta al equipo cuando dependa de componentes que todavía no estén integrados.

## 7. Soporte
Si encuentras errores o una sección no funciona, registra el mensaje, identifica la página afectada e informa al equipo de desarrollo.
